# Quotes Analysis (Web Scraping + Excel)

This project scrapes inspirational quotes and their authors from 
quotes.toscrape.com, analyzes author frequency, and exports the 
data to a formatted Excel file.

## Tools Used
- Python
- Requests
- BeautifulSoup (HTML parsing)
- Pandas (data analysis)
- OpenPyXL

## Features
- Multi-page scraping
- Duplicate removal
- Author frequency analysis using value_counts()
- Professional Excel export with bold headers

## Output
Generates an Excel report containing quotes with their authors, 
along with a console summary showing how many quotes each author has.
